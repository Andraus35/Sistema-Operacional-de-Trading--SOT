Trecho literal (verbatim, >100 caracteres):
"Risk-tiered approval pauses agents only for the decisions where human judgment actually changes the outcome, with enough context to make those decisions meaningful. Risk classification itself can't rely on an LLM exposed to the same untrusted content as the request being evaluated, because adversarial content could influence the classifier into marking the request as low-risk. Use deterministic logic (policy engines, rule-based classifiers) as the authoritative signal, with LLM-assisted classification as an optional input that a deterministic layer re-checks."

Trecho literal adicional (anti-padrão de parada/escalonamento):
"Implementing approval workflows without timeout policies or escalation paths, so agent execution stalls indefinitely when reviewers are unavailable."

Trecho literal adicional (registro auditável da decisão de aprovação):
"You log human approval decisions with timestamps and reviewer identities, creating an auditable record of human oversight for compliance purposes."
