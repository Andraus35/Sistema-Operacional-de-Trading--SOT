"When you make database changes, you open a transaction, make the required changes, and write
an event into a special outbox table."
"It's possible to reduce this polling interval - but this would mean increasing number of queries
to PostgreSQL database. We can do slightly better. Centrifugo supports LISTEN/NOTIFY mechanism of
PostgreSQL to be notified about new data in the outbox table."

"LISTEN/NOTIFY is an optimization rather than a complete alternative to polling."
"LISTEN/NOTIFY can drop messages, which defeats the durability and at-least-once guarantees

Papel no Dossie: sustenta o ponto de engenharia de que a NOTIFICACAO (push) e uma OTIMIZACAO
sobre o log duravel, nao a fonte de verdade — a durabilidade/ordem continua no log append-only
(SPEC-004). Reforca a recomendacao de camada fina de notificacao com cursor, nao broker duravel
paralelo.
