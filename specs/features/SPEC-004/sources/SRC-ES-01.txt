Trecho literal (verbatim conforme retornado pela WebSearch das fontes acima, 2026-10-03):
"Event Sourcing is an architectural pattern that tracks changes in a domain by recording them as
immutable domain events in an append-only event store. The system state is reconstructed by
replaying events from an append-only log."
"events being append-only — never updated or deleted ... the current state can be derived by
replaying all events in sequence ... which provides complete auditability and enables powerful
capabilities like time travel queries."
