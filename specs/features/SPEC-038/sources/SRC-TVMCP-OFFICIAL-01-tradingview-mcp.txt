OBSERVAÇÃO DE CONFORMIDADE (ToS geral do TradingView — ver SRC-TOS-01):
A documentação do MCP NÃO traz termos de uso próprios. Os Termos gerais do TradingView
(SRC-TOS-01, capturados 2026-10-02) licenciam dados para "exclusive display-only use" e
proíbem "algorithmic decision-making" e "non-display usage". Se o MCP oficial herda esses
Termos gerais para o dado que entrega, o uso não-display (alimentar análise algorítmica do
SOT) permanece em tensão com o ToS — ponto a ESCLARECER com o suporte do TradingView
(não decidido aqui; é [DECISÃO NECESSÁRIA] de Andraus). INDETERMINADO: a página do MCP
não foi observada declarando exceção ao ToS geral para uso via MCP.
